# Changelog

## 0.1.0 (2026-09-24)
- First build: 1:1 clone of tailor-by-octaboot.vercel.app in Next.js 16 with
  GSAP 3.12.5 ScrollTrigger, 535-frame canvas scrub, seven editorial panels,
  loader, hide-on-scroll header, outro and footer.
- Regression checks: element overflow at 320 to 414px, scroll scene state at
  nine scroll fractions.
